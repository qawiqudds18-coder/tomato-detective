      How a smart harvester spots ripe tomatoes

      1. The webcam takes a picture

        A camera on the Smart Harvest robot looks at the tomato plant.

      2. The Raspberry Pi reads the colours

        It converts each pixel to hue, saturation and brightness (HSV). Hue makes "how red is it?" easier to measure under changing light.

      3. It keeps only the red range

        Pixels inside the ripe-red hue range are kept. Green, orange and pink fall outside it.

      4. The arm reaches for the target

        Red pixels are grouped into tomato-shaped blobs. The position of each blob tells the robotic arm where to reach.

      Ripe red: pickTurningUnripe green: leave

      This game is a simulation

      In this game, you are the detector. The tomatoes are drawings, and the game already knows which ones are ripe. No camera, image processing or AI is running here.

      The real Smart Harvest prototype uses a webcam and colour-based detection on a Raspberry Pi. Real fields add shadows, leaves covering the fruit and different tomato varieties, so the colour ranges must be tested and tuned.
